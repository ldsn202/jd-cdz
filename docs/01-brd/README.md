# 01-brd 业务需求文档

当前文档：[京东充电桩工作台 2.0 BRD V1.1](BRD-jd-charging.md)，2026-09-19 已编写，待评审。

项目的业务需求文档（BRD）：为什么做这个项目、目标是什么、做哪些功能、不做什么。是后续原型、技术设计、PRD 的上游依据。

## 文件命名

```
BRD-<项目名>.md        例：BRD-任务管理工具.md
```

## 文件结构

结构以本目录下的 [`brd-template.md`](brd-template.md) 为准，固定 5 章：

| 章 | 内容 |
|---|------|
| 1. 项目背景 | 业务现状、问题与痛点、为什么现在做 |
| 2. 项目目标与成功标准 | 一句话目标 + 衡量指标表（口径 / 基线 / 目标值 / 周期） |
| 3. 目标用户与核心场景 | 角色表 + 每个角色的具体场景 |
| 4. 项目范围 | In Scope 功能点表 + Out of Scope 功能点表（带理由） |
| 5. 关键假设与风险 | 假设或风险、影响、应对方式 |

不适用的章节整体删除，不留空标题；也不额外加章节。

## 示例（范围章节的写法）

```markdown
## 4. 项目范围

### 4.1 In Scope（本期做）

| 功能点 | 一句话说明 |
|--------|-----------|
| 任务创建 | 用户填写标题和截止时间，创建一条任务 |
| 到期提醒 | 任务到截止时间前 1 小时推送提醒 |

### 4.2 Out of Scope（本期不做）

| 功能点 | 不做 / 推迟理由 |
|--------|----------------|
| 多人协作 | 依赖组织架构同步，二期再接 |
| 数据报表 | 与本期"提升任务完成率"目标无直接关系 |
```
