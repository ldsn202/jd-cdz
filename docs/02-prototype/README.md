# 02-prototype 高保真交互原型

当前原型：[京东充电桩工作台 2.0](index.html)。状态：V1.1 候选，待评审。

本项目按本轮要求采用高保真界面与可连续操作的前端模拟流程，覆盖原有低保真模板约定。

## 打开与体验

直接用浏览器打开 `index.html`，无需安装依赖、构建或联网。复制交付时保留同级 `assets/` 目录。

- 顶部身份选择器可切换六种角色。
- 从待处理事项进入，可查看证据、填写意见、提交决定和跟进结果。
- 数据与处理记录保存在当前浏览器；刷新继续，右下角“原型控制”可重置。
- 桌面优先，适配平板和窄屏；窄屏宽表格可横向滑动。

[页面清单](page-list.md) · [交互说明](interaction-spec.md)

## 文件结构

- `index.html`：原型入口，按路由切换页面。
- `assets/styles.css`：视觉规范、布局和响应式样式。
- `assets/state.js`：前端模拟数据与状态变化。
- `assets/app.js`：页面及交互。

原型仅模拟业务交互；不连接真实模型、业务接口、身份系统或支付系统。材料预览使用前端样例，上传文件可在当前浏览器查看，但不进行真实 AI 识别。原型的服务商原应收视图用于呈现跨系统交接，不代表已接入服务商系统。
