# 十家服务商、四个 Skill 的完整演示改造

日期：2026-09-27。开发模式：solo-local。执行状态：已完成（2026-09-27）。
归属：[T5.1 本地端到端联调](sub-delivery-plan-jd-charging-T5.1-e2e-integration.md)。用户已授权方案与实施、测试连续执行。

## 1. 依据和范围

已核对主 PRD、术语表、安装/配置/证据表结构、对外安装/材料/配置/对账接口、对应外部来源契约，以及安装资料、安装核查、配置、对账子 PRD。上述必需文件均存在。此次以最新用户口径修正旧文档中的自动分析与百家规模。

实施前缺口：原有十家数据只含 Excel 施工记录；映射启用后处理真实工单的路径没有完整演示；提取、提交、核查、补充全过程尚未在新数据上验收。旧图片依赖元数据描述，实际画面不足以支持逐项识别。初始化案例和上传文件缺少统一入口。

## 2. 实施顺序与验收

| 顺序 | 改造 | 完成标准 |
| --- | --- | --- |
| 1 | 固定十家服务商，保留正常、明确差异、明确缺项案例 | 来源、账号、列表均恰好十家；数据可重复生成；升级前完整归档 |
| 2 | 映射配置上传 Excel、试转换、启用并复用 | 显示原列→中文平台字段→实际转换值；同格式实际安装资料使用启用版本；跨服务商不可复用 |
| 3 | 安装资料提取 | 可读 Excel、PDF、PNG/JPEG 均有实际文件；实际施工数量与方案数量分别保留；人工确认后正式提交 |
| 4 | 安装核查与补充 | 提交成功产生京东核查事项；资料一致可确认；缺项可退回、服务商上传并回复、京东手动重分析再确认；保留历史 |
| 5 | 业务对账 | 金额及分项一致由程序核对；单价、数量差异调用真实 Skill，显示差额、依据及下一步；缺依据明确待补充 |
| 6 | 统一演示入口与中文展示 | 从初始化案例直接定位账号、事项及文件，保留正常业务列表；京东可读，服务商仅操作本家 |
| 7 | 初始化与回滚交付 | 项目根目录“测试用上传数据”含真实文件、README 和可核对清单；保存干净初始快照，重启不丢数据、不自动分析 |

## 3. 四个 Skill 的边界

| Skill | 输入与输出 | 必须实际完成的演示 |
| --- | --- | --- |
| provider-mapping-config | 服务商 Excel 样表、字段定义→映射建议 | 上传、试转换、启用、同格式复用；另有含义不明负例 |
| install-detail-extractor | 真实施工材料→实际安装明细草稿 | PDF/图片提取、人工确认提交、京东收到核查事项 |
| install-evidence-finder | 方案、正式明细、施工证据、补充→核查问题和依据 | 一致通过；缺材料退回、上传回复、再次核查 |
| billing-diff-explainer | 程序算出的差异、合同与批准记录→差异解释 | 单价差异与数量差异均形成可办理结果；一致案例不调用模型 |

## 4. 测试与证据

生成器验证全部十家及全部账单算术；自动测试覆盖权限、上传、映射隔离、旧版本保护、手动触发和幂等。真实模型仅运行清单中的代表事项，不批量消耗模型。浏览器实际验证上传、材料阅读、中文结果、角色切换与处理动作。每个验收结果记录具体工单、账号、输入、真实返回及持久结果，不能以按钮存在或返回 202 代替成功。

文件：Excel 首行为业务列名，无公式；PDF 与图片画面完整显示工单、项目、数量、单位、供料方和服务范围；不将隐藏元数据当作识别成功依据。文件中的预期值与源端初始化事实一致。

## 5. 保留约束

所有分析仅由事项详情的运行按钮触发，旁注“当前为 mock 环境，数据为演示数据，因此改为手动触发。”上传、启用、提交、补充及重启均不能悄悄启动模型。人工决定仍由对应业务账号作出。模型不计算应付金额、不自行审核、不编造成功结果。密钥只留本机 OpenCode 用户配置。

本次完成判据为以上七项全部有证据；云端发布不在此次范围。失败必须修复并重测，不能将预期正常案例降级为负例。

## 6. 完成结果

七项实施与本轮本地验收已完成。本地演示改造已完成并验收：demo-10-v4 固定10家服务商、100工单、154初始事项；四类 Skill 的代表业务链路均已真实运行，覆盖映射启用后复用、安装提取与提交、京东核查、退回上传补充再确认、单价及数量差异。逐项一致账单不调用 AI。17份实际上传文件及逐步 README 已放入“测试用上传数据”。169项自动回归、37项来源校验、类型检查与构建通过；最终回滚并重启后全部待手动运行，模型任务和业务写入均为0。旧百家规模、自动分析和缺模型凭证的历史描述已被本条覆盖。
