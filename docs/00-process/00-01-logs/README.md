# 00-01-logs 开发日志

每天一个文件，记录当天做了什么、产出了什么、遇到什么问题、明天接什么。是复盘和次日开工的依据。

## 文件命名

```
YYYYMMDD.md        例：20260822.md
```

## 文件结构

每份日志固定 6 章，顺序不变；当天没有内容的章写"无"，不删除章节。

| 章 | 标题 | 内容 |
|---|------|------|
| 一 | 执行概要 | 一张表：今天做了哪几件事、结果如何 |
| 二 | 操作详情 | 每件事的目标 / 操作 / 结果 / 涉及文件 |
| 三 | 变更总览 | 文件变更清单 + 当天 git 提交记录 |
| 四 | 发现的问题 | 今天暴露的 bug 或风险，没有写"无" |
| 五 | 复盘 | 做得好的、踩的坑、可沉淀为规则的经验 |
| 六 | 待跟进事项 | 明天要做的 checkbox 清单 |

## 示例

```markdown
# 开发日志 2026-08-22

## 一、执行概要

| # | 任务 | 结果 |
|---|------|------|
| 1 | 完成任务列表接口联调 | 完成 |
| 2 | 修复已完成任务计数不刷新 | 完成 |

## 二、操作详情

### 任务 1：完成任务列表接口联调
- **目标**：前端任务列表接通后端 `/api/tasks`
- **操作**：对齐入参口径，处理空列表兜底
- **结果**：列表正常渲染，空态展示"暂无任务"
- **涉及文件**：`src/views/TaskList.vue`、`src/api/task.js`

## 六、待跟进事项
- [ ] 任务接口加分页
- [ ] 跟后端确认任务列表的排序字段
```

同日有后续产出时，在文件末尾追加 `## 补充更新（HH:MM）`，不覆盖已有内容。
