# 首页统计卡片点击验证

日期：2026-09-27

## 原因与修改

原卡片为静态 article，没有导航行为；列表接口仅接受单个状态。现为可键盘访问的整卡链接，状态定义由计数与链接共同使用。接口支持校验后的状态并集，在权限范围内过滤后统计与分页。

## 实际检查

| 入口/操作 | 结果 |
| --- | --- |
| 待我确认 | READY，进入“我负责的”，列表6条且均待处理 |
| 等待补充/回复 | WAITING_SUPPLEMENT与WAITING_REPLY，0条空态，可清除筛选 |
| 系统处理中 | PREPARING与PROCESSING，状态框显示“系统处理中”；支持第2页 |
| 异常与受阻 | EXCEPTION与BLOCKED，卡片43条、列表43条 |
| 刷新 | 待我确认责任范围及READY筛选保留 |
| 浏览器后退 | 系统处理中第2页返回第1页，组合状态保留 |
| 最终页面 | 已返回首页，四卡显示进入箭头，整卡为链接 |

后台继续自动分析，检查期间系统处理中由1052变为1051、受阻由42变为43；跨请求差异来自状态变化，不固定卡片快照冒充当前结果。隔离测试使用不变化的数据库验证统计与列表一致。
