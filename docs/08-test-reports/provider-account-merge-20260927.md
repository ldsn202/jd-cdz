每家服务商统一一个账号，拥有本公司的接入配置、安装资料、补充与对账回复权限，页面统一显示“服务商”；公共 acc-jd-config 停用并从切换列表移除。100条配置事项按所属公司迁移，历史保留。标准账号现为京东1个+服务商100个。实际核对100家公司全部授权范围仅含自身，001/002账号配置跨公司读取双向404；隔离测试覆盖跨公司修改拒绝、迁移幂等及后续责任分配。原1000工单/1400事项保留，首次生成与旧环境升级一致。

新增4项服务商账号测试、4项京东账号/生成回归及5项既有切换测试通过；模拟服务类型检查、前端类型检查与构建通过；Safari确认账号名称与列表。未重跑模型或提交业务决定，T5.1保持进行中。

| 实测项目 | 结果 |
| --- | --- |
| 账号列表 | 101个人类账号；1个京东、100个服务商，无公共对接账号 |
| 授权范围 | 100家公司共300条动作授权，每条仅含本公司；同一账号拥有配置、资料和应收职责 |

| 新来源生成 | 每家公司一个 PROVIDER_BUSINESS 账号，不生成公共 acc-jd-config |
| 后续责任 | 配置、草稿确认、补充和对账回复均解析到本公司同一主体 |
