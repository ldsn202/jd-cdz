1. 接收与可恢复任务

2. 实际执行与当次授权

3. 能力调用与固定结果

两种输入和两种输出按操作互斥；调用得到结果后，更新事项仍须检查是否过期。

4. 人员确认与业务写入

业务写入编号保持稳定。变化提示须与确切原动作证据匹配，不用通知替代成功回执。
