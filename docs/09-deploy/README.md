# 09-deploy 部署与运行配置

接收方 AI 先读项目根 [启动与运行指南](../../启动与运行指南.md)，按文档安装依赖并恢复可见业务数据；内部调试细节见 [local-setup.md](local-setup.md)。

## 文件命名

```
local-setup.md         本地启动：环境要求、安装步骤、启动命令、验证方式
cloud-deploy.md        云端部署：部署目标、发布步骤、回滚方式
config-items.md        配置项总表：全部环境变量和配置项的口径
api-keys.md            密钥台账：每个密钥的用途、申请渠道、维护人
```

## config-items.md 结构

| 列 | 说明 |
|----|------|
| 配置项 | 环境变量名，如 `DB_HOST` |
| 用途 | 控制什么 |
| 本地值 | 本地开发填什么 |
| 云端值 | 云端填什么（或"见密钥台账"） |
| 必填 | 缺了会怎样 |

## api-keys.md 结构

| 列 | 说明 |
|----|------|
| 密钥 | 名称，如"推送平台 AppKey" |
| 用途 | 哪个功能在用 |
| 申请渠道 | 找谁、在哪个平台申请 |
| 存放位置 | 配在哪个环境变量 / 哪个密钥管理工具 |
| 维护人 | 过期或泄漏时找谁 |

**红线：密钥的真实值一律不写进本目录。** 这里只登记"这个密钥是什么、去哪拿、配在哪"。真实值走密钥管理工具或平台环境变量，不进 git。

## 示例（config-items.md 节选）

```markdown
| 配置项 | 用途 | 本地值 | 云端值 | 必填 |
|--------|------|--------|--------|------|
| DB_HOST | 数据库地址 | localhost:3306 | 见密钥台账 | 是，缺了服务起不来 |
| PUSH_APP_KEY | 推送平台鉴权 | 申请测试 key | 见密钥台账 | 否，缺了提醒功能降级 |
| TASK_PAGE_SIZE | 任务列表每页条数 | 20 | 20 | 否，有默认值 |
```

## 示例（local-setup.md 节选）

```markdown
## 本地启动
1. 环境：Node 20+、MySQL 8（可用 Docker 起）
2. `cd code && npm install`
3. 复制 `.env.example` 为 `.env`，按 config-items.md 填本地值
4. `npm run dev`
5. 验证：浏览器打开 http://localhost:3000，任务列表页能打开即成功
```
