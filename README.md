# 京东充电桩管理平台

**启动入口：[启动与运行指南.md](启动与运行指南.md)。**

将本工作区交给接收方 AI，让它阅读指南并完成依赖安装、模型配置检查、数据初始化、启动与验证。日常停止、角色切换、保存起点与回滚也统一按该指南执行。

OpenCode 桌面客户端用于配置个人模型凭证，后台 CLI 执行业务 Skill。密钥留在使用者个人 OpenCode 配置中。分享前按指南排除本机运行目录、数据库、缓存和个人凭证；接收方启动时自行初始化标准业务来源。

技术细节见 [本地部署说明](docs/09-deploy/local-setup.md)。

**演示入口：[测试用上传数据/README.md](测试用上传数据/README.md)。** 已备好十家服务商的初始化案例及 17 个真实上传文件，按账号、事项、操作步骤与预期结果逐项说明。四个业务 Skill 均从事项详情手动运行；首页“初始化演示案例”可直接进入。

本轮实现与测试结果：[四类 Skill 完整演示验收](docs/08-test-reports/four-skills-demo-20260927/README.md)。
