# 五类资料形态版式规格（生成器固定布局）

> 本目录为生成器版式基线；实际布局由 `code/mocks/generator/generate-files.ts` 按本规格生成，两次同配置生成字节一致。

## 1. 字段清楚的表格（clear_table，XLSX）

- 单 sheet `施工记录`：表头 `安装工单 / 项目 / 数量 / 单位 / 供料方 / 服务范围`，每行一个项目，工单号逐行重复。

## 2. 同义字段但结构不同的表格（restructured_table，XLSX）

- 双 sheet：`分段记录`（首行工单号，表头 `段号 / 项目 / 供料 / 安装`，数量带单位嵌入文本）+ `汇总`（首行工单号，`项目 / 合计数量 / 单位`）。
- 与 clear_table 字段同义（供料≈供料方数量），但结构、拆行与单位表达不同。

## 3. 计量表达不同的表格（alt_unit_table，XLSX）

- 单 sheet `记录`：首行工单号，表头 `项目 / 计量表达 / 折算数量 / 单位`。
- 计量表达形如 `22m`、`6段×4米`，折算数量列为十进制米数；程序必须执行换算，不能只读数值列。

## 4. PDF 施工记录（pdf_record）

- 两页：第 1 页标题/安装工单/服务商/记录日期；第 2 页项目数量行（`项目 数量单位 供料方 范围`）。
- 变更确认单为独立单页 PDF：工单号 + 变更说明。
- Type0 STSong-Light/UniGB-UCS2-H；固定 Creator 与 CreationDate。

## 5. 图片施工记录（image_record，JPEG/PNG）

- 光栅：640×400，5×7 点阵 ASCII 标注工单号与项目数量（`WO-...`、`59M`、`28X`）。
- 文本层分开两段：`Description`（图片描述：画面内容说明）与 `ExtractedText`（识别原文：含工单号、项目、数量的逐行文本）；PNG 存 iTXt，JPEG 存 COM JSON。
- 图片形态按材料序号奇偶交替 JPEG/PNG。

## 负例版式

- NEG-F1 损坏：正常 PDF 截断至 60%（trailer/xref 丢失），解析必须失败。
- NEG-F2 缺页：清单需要 2 页、实际仅生成第 1 页，解析必须报缺页。
